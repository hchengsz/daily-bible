# Expo SDK documentation

This project currently uses Expo SDK 57 (`expo` version `^57.0.24`).

Before writing Expo code, check `package.json` and `package-lock.json` for the project's actual SDK version. Read the matching versioned documentation; for SDK 57, use https://docs.expo.dev/versions/v57.0.0/.

After an SDK upgrade, update this file and the README's tech stack. If the versioned documentation is unavailable, inspect the installed packages' types and source to confirm API support. Do not assume that older SDK documentation or the `latest` documentation matches the installed version.
